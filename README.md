# FinFET Circuit Design and Characterization

A structured portfolio of notes, labs, and assignments from a hands-on course covering FinFET devices from first principles through 7nm PDK simulation and analog circuit design.

```

└── Module_3_Bandgap_References/         ← Design: analog bandgap using 7nm FinFETs
```
